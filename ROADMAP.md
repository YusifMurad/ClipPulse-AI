# 🗺️ ClipPulse AI — Public Roadmap

We plan in the open. This is a living document — items move as we ship.
Vote or comment in [Discussions · Ideas](https://github.com/YusifMurad/ClipPulse-AI/discussions/categories/ideas).

## ✅ Shipped

- AI clip selection via Gemini 3.6 Flash
- 9:16 vertical reframe with FFmpeg
- OpusClip-style animated subtitles (word highlight, smart wrap)
- 14-language transcription (Faster-Whisper)
- Local MP4 upload
- Browser clip editor (trim + re-caption)
- Auto thumbnail generation
- API key stored server-side, never sent to client
- Rate limiting
- Multi-language README (EN/TR/ES/AR/ZH)
